# Analytics & Privacy

## Overview

The AI Testing Agent collects anonymous usage statistics to help improve the tool. All analytics are:

- Anonymous — no personal data collected
- Transparent — clear about what is collected
- Opt-out supported — multiple ways to disable
- Non-blocking — never interrupts your workflow
- Graceful — failures are silent and don't crash the app

## What We Collect

### Data we DO collect

1. **Usage events** — tool started, test generation started/completed, errors
2. **Performance metrics** — endpoints processed, tests generated, duration, success/failure

### Data we DON'T collect

- No personal data (name, email, etc.)
- No IP addresses
- No requirements content or business logic
- No generated code or test data

## Anonymous User ID

Generated by hashing the machine hostname with SHA256, truncated to 16 characters. Cannot be reversed.

## Opt-Out

**Environment variable (recommended):**
```bash
export AI_AGENT_TELEMETRY=false
# or permanently:
echo 'export AI_AGENT_TELEMETRY=false' >> ~/.bashrc
```

**Config file:**
```bash
mkdir -p ~/.ai-testing-agent
echo '{"telemetry_enabled": false}' > ~/.ai-testing-agent/config.json
```

**CLI flag (single command):**
```bash
python cli.py run requirements.txt --no-telemetry
```

## Analytics Commands

```bash
python cli.py analytics          # show status
python cli.py analytics-disable  # disable permanently
```

## Technical Details

Analytics requests are sent in background threads with a 2-second timeout. If the server is unavailable, the tool continues working normally with no error messages or retries.

## FAQ

**Can you identify me from the anonymous ID?**
No. It is a one-way SHA256 hash. Mathematically impossible to reverse.

**Does analytics slow down my tool?**
No. Background threads with 2-second timeout. Your workflow is never blocked.

**What if the analytics server is down?**
Nothing. Fails silently. No impact on the tool.

**To re-enable after disabling:**
Delete `~/.ai-testing-agent/config.json`, or unset the `AI_AGENT_TELEMETRY` environment variable.
