# Analytics & Privacy Documentation

## Overview

The AI Testing Agent includes **privacy-first analytics** to help improve the product while respecting user privacy. All analytics are:

- ✅ **Anonymous** - No personal data collected
- ✅ **Transparent** - Clear about what's collected
- ✅ **Opt-out supported** - Multiple ways to disable
- ✅ **Non-blocking** - Never interrupts your workflow
- ✅ **Graceful** - Failures are silent and don't crash the app

## What We Collect

### ✓ Data We DO Collect

1. **Usage Events**
   - Tool started/stopped
   - Test generation initiated
   - Test generation completed
   - Errors encountered

2. **Tier Information**
   - Which tier you're using (free/pro/team/enterprise)
   - Upgrade prompts shown

3. **Performance Metrics**
   - Number of endpoints processed
   - Number of tests generated
   - Execution duration (seconds)
   - Success/failure status

4. **Error Types** (category only)
   - `api_error`, `license_invalid`, `limit_exceeded`
   - **NO** error messages or stack traces

### ✗ Data We DON'T Collect

- ❌ **NO personal data** (name, email, etc.)
- ❌ **NO IP addresses** (anonymized at collection)
- ❌ **NO requirements content** (your business logic stays private)
- ❌ **NO generated code** (your tests are yours)
- ❌ **NO test data** (no test inputs or outputs)
- ❌ **NO license keys** (only hashed anonymous IDs)

## Anonymous User ID

Your anonymous ID is generated by:
1. Hashing your license key with SHA256
2. Truncating to 16 characters
3. Result: `f6e7bea6d40f3ae0` (cannot be reversed)

**For free tier users without a license key:**
- Machine-based ID using hostname
- Still completely anonymous

## Opt-Out Methods

You can disable analytics using **any** of these methods:

### Method 1: Environment Variable (Recommended)

```bash
# Disable for current session
export AI_AGENT_TELEMETRY=false

# Disable permanently (add to ~/.bashrc or ~/.zshrc)
echo 'export AI_AGENT_TELEMETRY=false' >> ~/.bashrc
```

### Method 2: Config File

```bash
# Create config directory
mkdir -p ~/.ai-testing-agent

# Create config file
echo '{"telemetry_enabled": false}' > ~/.ai-testing-agent/config.json
```

Or use the CLI command:

```bash
python cli.py analytics-disable
```

### Method 3: CLI Flag

Disable for a single command:

```bash
python cli.py run requirements.txt --no-telemetry
```

## Technical Implementation

### Non-Blocking Design

All analytics requests are sent in **background threads** that:
- Don't block your workflow
- Use a 2-second timeout
- Fail silently if server is down
- Never raise exceptions

```python
# Example: Event tracking is non-blocking
analytics.track_event("test_started", {"tier": "pro"})
# ↑ Returns immediately, sends in background
```

### Graceful Failure

If the analytics server is unavailable:
- ✅ Your tool continues working normally
- ✅ No error messages shown (silent failure)
- ✅ No data is queued or retried
- ✅ No impact on performance

### Integration Points

Analytics are integrated at key workflow points:

1. **Tool Startup**
   ```python
   analytics.track_tool_started(tier)
   ```

2. **Test Generation Start**
   ```python
   analytics.track_test_generation_started(endpoint_count)
   ```

3. **Test Generation Complete**
   ```python
   analytics.track_test_generation_complete(
       endpoints=50,
       tests_generated=100,
       duration_seconds=45.2,
       success=True
   )
   ```

4. **Errors**
   ```python
   analytics.track_error("api_timeout")
   ```

5. **Upgrade Prompts**
   ```python
   analytics.track_upgrade_prompt_shown("free", "pro", "endpoint_limit")
   ```

## FAQ

### Q: Can you identify me from the anonymous ID?

**A:** No. The anonymous ID is a one-way SHA256 hash truncated to 16 characters. It's mathematically impossible to reverse this to get your license key.

### Q: What if I don't trust the analytics?

**A:** You can easily disable it using any of the opt-out methods. The tool works perfectly fine with analytics disabled.

### Q: Do analytics requests slow down my tool?

**A:** No. All requests are sent in background threads with a 2-second timeout. Your workflow is never blocked.

### Q: What happens if the analytics server is down?

**A:** Nothing. The request fails silently and your tool continues working normally. No error messages, no retries, no impact.

### Q: Why collect analytics at all?

**A:** It helps us understand:
- Which features are most used
- Where users encounter errors
- How to improve the product
- Which tiers need better features

All while respecting your privacy completely.

### Q: Is analytics enabled by default?

**A:** Yes, but:
- You're clearly informed on first use
- Easy opt-out methods provided
- Completely anonymous data only
- Non-blocking and graceful

### Q: Can I re-enable analytics after disabling?

**A:** Yes! Either:
1. Delete `~/.ai-testing-agent/config.json`
2. Edit the config file to set `telemetry_enabled: true`
3. Unset the `AI_AGENT_TELEMETRY` environment variable
