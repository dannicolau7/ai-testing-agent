## ❓ Frequently Asked Questions

### General

**Q: Is the FREE tier really free forever?**  
A: Yes! The FREE tier is open source (MIT License) and will always remain free. No credit card required, no time limits, no hidden costs.

**Q: Can I try PRO/TEAM before buying?**  
A: Yes! We offer a 14-day free trial for both PRO and TEAM. No credit card required during trial.

**Q: What if I'm not satisfied?**  
A: We offer a 30-day money-back guarantee on all paid plans. No questions asked.

**Q: Do I need an Anthropic API key?**  
A: FREE tier doesn't need any API key. PRO/TEAM/ENTERPRISE need an Anthropic API key for real Claude AI (you provide your own).

### Usage & Limits

**Q: How is a "run" calculated?**  
A: A run is one complete execution of the autonomous workflow (requirements → tests → report). Checking usage or tier info doesn't count.

**Q: How are "endpoints" calculated?**  
A: An endpoint is a single API endpoint, feature, or component being tested. The AI detects these from your requirements.

**Q: What happens if I exceed my limits?**  
A: 
- **FREE tier:** You'll see a warning at 80% usage and a friendly message at 100%. You can upgrade or wait for monthly reset.
- **PRO/TEAM:** No monthly run limits! Endpoint limits only apply per-run, not monthly.

**Q: When do monthly limits reset?**  
A: On the 1st of each month at 00:00 UTC.

**Q: Can I check my current usage?**  
A: Yes! Run `python cli.py usage` to see detailed usage statistics.

### Billing & Payments

**Q: How do I pay?**  
A: We accept all major credit cards (Visa, Mastercard, Amex, Discover) and PayPal. Enterprise can pay via invoice.

**Q: Can I switch plans?**  
A: Yes! You can upgrade or downgrade at any time. Upgrades take effect immediately. Downgrades take effect at next billing cycle.

**Q: What about annual billing?**  
A: Annual plans save 17%:
- PRO: 
- TEAM: 

**Q: Are there any hidden fees?**  
A: No! The price you see is what you pay. No setup fees, no hidden costs. You pay for your own Anthropic API usage separately.

**Q: Can I cancel anytime?**  
A: Yes! Cancel anytime from your dashboard. No cancellation fees. Your account remains active until the end of your billing period.

**Q: What happens to my data if I cancel?**  
A: All generated tests are yours forever. You can export everything before canceling. We keep your data for 30 days after cancellation.

### Technical

**Q: Does it work offline?**  
A: The FREE tier with mock AI works completely offline. PRO/TEAM/ENTERPRISE need internet for Claude API.

**Q: What Python version is required?**  
A: Python 3.8 or higher.

**Q: Can I use it in CI/CD?**  
A: Yes! Works great with GitHub Actions, GitLab CI, Jenkins, etc. See our [CI/CD guide](docs/cicd.md).

**Q: Is my data secure?**  
A: Yes! Your requirements and tests never leave your machine in FREE tier. In paid tiers, we only send data to Anthropic's Claude API (which has enterprise-grade security). We never store your code.

**Q: Can I customize the generated tests?**  
A: Absolutely! All generated code is yours to modify. PRO+ tiers offer custom templates.

### Support

**Q: What support do I get with FREE?**  
A: Community support via GitHub Issues, forum, and Stack Overflow. Plus comprehensive documentation.

**Q: How fast is PRO support?**  
A: 24-hour response time on business days. Usually faster!

**Q: Do you offer phone support?**  
A: Phone support is available for ENTERPRISE customers only.

**Q: Can I get help with implementation?**  
A: FREE/PRO: Documentation and community. TEAM: Group webinars. ENTERPRISE: Personalized onboarding and training.

### Licensing

**Q: What license is FREE tier under?**  
A: MIT License - free to use, modify, and distribute, even commercially.

**Q: Can I use FREE tier in a commercial product?**  
A: Yes! MIT License allows commercial use. Attribution appreciated but not required.

**Q: Do I need a separate license for each developer?**  
A: FREE/PRO: One developer. TEAM: Up to 10. ENTERPRISE: Unlimited.

**Q: Can I host this on my own servers?**  
A: FREE tier: Yes (MIT License). Paid tiers: ENTERPRISE only has on-premise option.
