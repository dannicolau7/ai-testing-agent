# Test Specifications Directory

This directory contains API specifications and test automation scripts for the AI Testing Agent.

## 📁 Contents

- **test_stripe_api_keys.txt** - Stripe API Keys Authentication specification
- **run_stripe_test.sh** - Automated test generation script

## 🚀 Quick Start

### Method 1: Using the Automation Script (Recommended)

```bash
# From the test_specs directory
./run_stripe_test.sh
```

### Method 2: Using the CLI Directly

```bash
# From the project root
python cli.py run test_specs/test_stripe_api_keys.txt
```

### Method 3: Using the One-Liner (Shell)

```bash
cat > test_specs/test_stripe_api_keys.txt << 'EOF'
[Your API specification content]
EOF

python cli.py run test_specs/test_stripe_api_keys.txt
```
